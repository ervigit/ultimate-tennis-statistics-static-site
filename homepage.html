Ultimate Tennis Statistics

This is the most complete app to collect statistics for tennis match. C'est l'application la plus complète pour collecter des statistiques pour un match de tennis.

The only app which texts the score as the match is played! La seule application qui envoie le score par texto au fur et à mesure que le match est joué !

In this era of data, if you want to improve your tennis skills, you need data. This app is exactly for that. It allows to note, for each point in the match, the way each point ended and you can afterwards watch a whole batch of statistics. En cette ère des données, si vous voulez améliorer vos compétences au tennis, vous avez besoin de données. Cette application est exactement pour cela. Elle permet de noter, pour chaque point du match, la façon dont chaque point s'est terminé et vous pouvez ensuite regarder tout un ensemble de statistiques.

Features Fonctionnalités

Here are the main features: Voici les fonctionnalités principales :

  • easily enter the way each point has ended entrez facilement la façon dont chaque point s'est terminé
    • ace, service winner, service return ace, service gagnant, retour de service
    • winner, unforced error, forced error coup gagnant, faute directe, faute provoquée
    • forehand, backhand coup droit, revers
    • topspin, slice, volley, smash, drop, passing, swing volley lift, slice, volée, smash, amortie, passing, volée liftée
    • note the attitude and routine of each player notez l'attitude et la routine de chaque joueur
    • you can even write a note on a point vous pouvez même écrire une note sur un point
  • score is then computed automatically le score est ensuite calculé automatiquement
  • jump to a specified score if you missed some part of the match sautez à un score spécifié si vous avez manqué une partie du match
  • share the score as the match goes (by sending text messages) partagez le score au fur et à mesure du match (en envoyant des textos)
    • at each point à chaque point
    • at the end of each game à la fin de chaque jeu
    • at the end of each set à la fin de chaque set
  • look the match statistics regardez les statistiques du match
    • for the whole match pour l'ensemble du match
    • for each set pour chaque set
    • at net au filet
    • on pressure points at 30-30 or 40-40 sur les points sous pression à 30-30 ou 40-40
    • when score is 15-30 quand le score est de 15-30
    • the stats can be easily shared as an image or a CSV file les stats peuvent être facilement partagées sous forme d'image ou de fichier CSV
  • show a the graph of the match to look for trends affichez le graphique du match pour observer les tendances
    • each point of the graph is button to look exactly what happened at that point chaque point du graphique est un bouton pour voir exactement ce qui s'est passé à ce point
    • it can be easily shared as an image il peut être facilement partagé sous forme d'image
  • share the match partagez le match
    • so another user can open the match in its own device and look for the statistics or graphs afin qu'un autre utilisateur puisse ouvrir le match sur son propre appareil et consulter les statistiques ou les graphiques
  • all match formats are supported tous les formats de match sont pris en charge
  • all the matches are kept so you can review your tennis statistics afterwards tous les matchs sont conservés afin que vous puissiez revoir vos statistiques de tennis par la suite

The Pro subscription allows to store an unlimited number of matches win your library and to qualify each strokes more precisely: L'abonnement Pro permet de stocker un nombre illimité de matchs dans votre bibliothèque et de qualifier chaque coup plus précisément :

  • winner, forced error coup gagnant, faute provoquée
    • deep, short profond, court
    • crosscourt, parallel, inside-in, inside-out croisé, parallèle, décroisé, long de ligne
  • unforced error faute directe
    • side of the court the ball was out côté du court où la balle est sortie
  • 2nd stroke after service or after return 2e coup après le service ou après le retour
